## 新增测试覆盖

### 解析

- 官方 wire 布局的手写合成日志；来源 ID、声明版本、时间和生成标题。
- 消息与事件副本不重复；相同正文的不同记录不按文本去重。
- BOM、CRLF、空行、缺省 legacy 和旧 session_id 字段兼容。
- developer 映射提示、推理/工具/未知响应/运行元数据不冒充普通答复。
- 多模态、加密内容、阶段和完成状态损失报告；引用不被访问。
- 压缩替代历史不重复展开，回退历史不冒充有效分支。
- 分页、历史继承、fork、父线程、子会话源、根 session_id 不一致拒绝。
- 多会话拼接、未知顶层类型、错误角色、显式 ID 重复、时间/对象/正文类型错误与截断拒绝。
- 错误包含行号，不回显正文秘密；20,000 物理行、512 KiB 单行、10,000 消息限制。

### 存储与桌面

- 预览不落盘，确认后保存精确 JSONL 原件与来源报告。
- 相同字节文件重复导入复用已有会话；截断输入不新建档案。
- 桌面选择框允许 `.jsonl`，两条消息不被事件副本扩成四条。
- HTML 字样只显示为文本；来源筛选、导入报告、带报告交接、v2 包导出和重启加载。
- 先前 Cindy、Staithe / Ember、文件取消、沙箱、深链、开发启动测试均继续通过。

测试只用合成文件和隔离 userData。文件对话框与剪贴板使用替身；未读取真实会话、凭据或客户端数据库。所有失败先通过 TDD 复现，再完成实现和最终绿灯验收；没有放宽覆盖率门槛。

## 验收边界与下一步

- `fixture-tested` 不等于真实发布客户端实测。输入 CLI 版本仅是声明，不能由此声称支持某个真实发布版本。
