# Windows 适配与验收

更新：2026-10-23。

## 首版范围

Windows 首版以 **连接日志来源 → 浏览／搜索 → 阅读 → 保存完整接续文件** 为目标。目前有代码适配和 CI 配置，尚未完成 Windows 原生运行与安装包实机验收，不能标为正式可发布。

- 日志来源：Claude Code、Codex、DeepSeek Harness、WorkBuddy、Qwen Code，继续遵守各自版本与内容边界。
- 主按钮「保存接续文件」：通过现有令牌接口重新读取完整可读历史，以系统保存框选择 `.md` 文件；取消不显示成功，不静默复制正文或路径。
- NewMax／Cindy：非 macOS 暂不支持安全数据库直读，卡片提前解释平台限制，禁用新连接及自定义位置入口。已有连接仍能断开，避免留下无法撤销的授权。
- 原生历史迁移：Windows 没有注册目标；能力检查确认没有已接入目标后隐藏高级迁移和目标设置入口。日志格式可读不代表客户端可恢复或可写入。
- 文件剪贴板：仍未实现 Windows 原生格式；不移除主进程平台拒绝逻辑，不把路径文本当作附件。

## 构建与自动验证

在 Windows 原生环境、仓库根目录执行：

```powershell
npm ci
npm run test:coverage
npm run build
node scripts/build-engine.mjs
npm run test:e2e
npm run dist:win
```

`dist:win` 先做类型检查和生产构建，再生成 x64 NSIS 安装包至 `release/`；现有多尺寸 ICO 直接复用，不要求运行 macOS 图标生成工具。Engine 使用当前 Node 运行已安装 TypeScript 的 JS CLI，不执行 Unix `.bin/tsc` shim。

GitHub Actions 配置 `macos-latest` / `windows-latest` 矩阵，在各平台执行覆盖率、生产构建、Engine 构建和桌面 E2E；Windows job 随后打包并上传 NSIS 测试安装包。两个系统的失败附件分开命名。没有触发／查看成功的 Windows 运行前，不能把配置存在当作 CI 已通过。

通用日志测试在 Windows 继续运行；实际依赖 macOS 沙箱 SQLite、应用包识别或 Unix 权限的成功测试按能力限定平台，不将整个 Windows 套件跳过。未实现能力应验证明确拒绝且无副作用。桌面自动测试仅使用合成数据、隔离 userData、剪贴板替身和文件框替身。

**本地桌面验证约束：** E2E 会启动额外 Electron。用户要求只复用主 dev、不重启、不抢焦点时，不自动运行这些测试；记录未运行原因。CI 配置不意味着获准在用户电脑启动副本。

## 安装包与签名

本批提供的是测试包构建入口，不是正式签名分发流程。CI 关闭证书自动发现，不配置或读取签名凭据；不要宣称包已签名、已公证、不会触发 SmartScreen，或已通过企业分发要求。正式分发前须另行确定证书／签名服务、时间戳、缺少签名时失败的门禁，以及最终产物验签。

本批 CI 测试运行生产构建中的应用，不运行 NSIS 安装／升级／卸载生命周期；安装成功和安装后启动必须另外验收。

## 待完成的 Windows 验收

以下全部为待验收项，不由 macOS、模拟 `platform: 'win32'` 或构建成功替代：

- 普通用户安装、安装后启动、重复启动；升级保留连接配置；卸载行为与协议关联。
- 合成日志连接、列表、搜索、长正文分页、刷新、断开；保存完整历史，文件内容和消息数量核对；取消／覆盖失败不虚报成功。
- 含中文／空格用户名、盘符大小写、跨盘、长路径；明确 UNC 支持边界。
- NTFS junction／符号链接、文件替换、来源活跃追加、读取权限不足、文件占用与原子替换失败。
- 125%／150%／200% 缩放、最大化、贴靠、多显示器、输入法、长提示与弹窗布局。
- Pinekin 深链冷启动／运行中投递；外部「查看原会话」须验证目标 App 真的选中正确会话。当前部分解析仍依赖 macOS 应用包，不承诺 Windows 客户端关联已实现。
- 保存文件上传目标 App 后被正确解析，并能继续下一轮对话；系统保存成功不等于目标已接收。
