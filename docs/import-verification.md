### 核心和集成覆盖

- 明文 Cindy 正常包、文本块/JSON 字符串/裸文本/未知结构、空消息列表。
- 工具元数据、媒体、回退内容的缺失报告，不执行、不联网补齐。
- 魔数精确匹配、头版本、保留位、加密/Orca/未来版本拒绝。
- 清单大小和散列、重复/缺失/未声明条目、角色/时间/消息 ID、截断 JSONL。
- ZIP 穿越、绝对路径、重复路径、特殊文件、压缩比、条目数和 CRC。
- 多个中央目录项重复引用有效空 DEFLATE 流：累计压缩处理预算阻止工作量放大。
- 输入 5 MiB 边界与超限，目录/缺失文件拒绝；隔离目录 FIFO 没有写端仍及时失败，后续普通文件可读。
- 预览不落盘、取消、过期、一次性 token、新旧异步预览竞争、快照复制。
- 并发同文件去重、写入失败重试、刷新后不复活失败预览、报告上限、坏旧库/坏归档/坏原件保护。

### 桌面 E2E 覆盖

1. 启动、搜索、来源筛选与沙箱。
2. Staithe v1 包预览/确认、持久化、坏输入。
3. Ember v1 兼容及旧环境变量。
4. Cindy 合成包预览、取消、源文件变更后仍提交原快照、重复定位、来源筛选、报告和交接、重启持久化。
5. 取消文件选择和加密包拒绝不产生档案。
6. 两种文本导出、剪贴板替身和交接面板关闭。
7. 旧默认目录及已有 ID 不被更名重写。
8. 新 Staithe 深链。
9. 旧 Ember 深链。
10. 开发入口隔离宿主环境并渲染 React。

所有输入都是合成数据；临时 userData、文件对话框返回值与系统剪贴板隔离。不使用真实客户端目录、凭据或会话测试。

加入锁定的运行依赖 `yauzl@3.3.0` 和开发类型 `@types/yauzl@3.4.0`。`npm audit --json` 当前报告 7 项 moderate、0 high、0 critical，告警来自既有 electron-builder → global-agent / roarr / sprintf-js 开发工具链；本次新增 ZIP 依赖未出现在告警条目中。未执行 `audit fix --force`，不将潜在破坏性工具链调整混入本批。

## 过程中的失败及修正

- 新功能测试先失败，再实现；未把这些 TDD 失败算作通过。
- 大 Buffer 的通用深比较曾令文件边界测试超过默认 5 秒；改为 `Buffer.equals()` 精确比较，未放宽超时或数据上限。
- 额外统计尝试发现当前安装树没有 `istanbul-lib-coverage`；没有为此安装依赖或重跑测试，直接核对已有 coverage JSON 和成功的覆盖率输出。
- 原始 Retina 截图超出读取工具尺寸限制，保留原图并在 `test-results/` 生成等比例预览副本后检查；这些产物均被 Git 忽略。
