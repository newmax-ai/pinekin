# 空占位规范

日期：2026-10-18。

## 目标与边界

统一来源直读、档案兼容入口、搜索和阅读区的空占位。空占位表达的是**当前范围的实际状态**，而不只是 `items.length === 0`。

- 保持原三栏布局、列表密度、标题字体、主题和导航方式，不新增常驻入口或另一套页面设计。
- 数据发现、按需读取、档案导入、上下文交接与原生恢复保持独立。空列表不代表客户端没有会话；没有可展示消息不代表附件、工具与运行态能够恢复。
- 占位渲染本身不扫描目录、不读取正文、不连接客户端、不上传数据。行动按钮只调用现有的显式授权与读取流程。
- 已有数据优先保留。分页／其他位置出错不能用全屏占位遮住已经可浏览的条目。

## 文案职责

- **标题说明当前状态**：回答「现在是什么情况」，不再用欢迎口号或操作邀请替代状态。例如「尚未连接会话来源」「尚未选择会话」。
- **描述补充新信息**：回答「原因、影响范围或可用能力是什么」，不能换句话复述标题，也不重复按钮动作。例如未连接时补充可选来源，未选择时说明此处会显示哪些信息。
- **按钮表达具体动作**：回答「可以做什么」，使用「连接来源 App」「刷新」「选择会话文件」等操作名；描述不再堆叠相同的操作指令。
- **真实诊断优先**：读取失败时使用实际原因替换默认描述，不追加第二段泛化说明。小空间仍只有一句提示，不强行拆分成三层。

| 场景 | 标题：状态 | 描述：补充信息 | 按钮：动作 |
| --- | --- | --- | --- |
| 未连接 | 尚未连接会话来源 | 支持 Claude Code、Codex 等来源。 | 连接来源 App |
| 待刷新 | 等待刷新 | 连接位置已保留，会话列表尚未更新。 | 刷新 |
| 未选择 | 尚未选择会话 | 正文与来源信息将在这里显示。 | 无 |
| 档案空库 | 还没有会话档案 | 导入前可预览内容与兼容性。 | 选择会话文件 |

## 状态判定与行动

来源页面仅使用**当前筛选范围**内的连接判定，顺序如下。上层条件成立即停止，不混合多套提示。

| 优先级 | 条件 | 显示状态 | 插画 | 主行动 |
| --- | --- | --- | --- | --- |
| 1 | 已有可展示条目 | 不显示列表空占位 | 无 | 保留正常列表与分页 |
| 2 | 列表请求失败 | 暂时无法读取会话列表 | 读取受阻 | 重新加载列表，不擅自刷新来源 |
| 3 | 首次列表请求未完成 | 正在读取来源目录 | 无，仅轻量进度 | 无 |
| 4 | 当前范围没有连接 | 尚未连接会话来源 | 等待连接 | 连接来源 App，进入已有连接弹窗 |
| 5 | 任一位置仍在统计 | 正在发现会话 | 无，仅轻量进度 | 无，已有轮询继续 |
| 6 | 任一位置读取失败 | 暂时无法读取来源 | 读取受阻 | 管理连接，查看位置与权限原因 |
| 7 | 任一位置部分可读 | 部分位置未能读取 | 读取受阻 | 刷新；不宣称完整零条 |
| 8 | 任一位置已暂停 | 会话统计已暂停 | 空文件盒 | 刷新，重新统计 |
| 9 | 任一位置仍待刷新 | 等待刷新 | 空文件盒 | 手动刷新；重启只恢复保存的授权位置，不自动扫描 |
| 10 | 全部完成、有效关键词、无结果 | 没有找到匹配的会话 | 放大镜 | 清空关键词，保留来源并恢复搜索焦点 |
| 11 | 全部完成、没有有效关键词、无条目 | 还没有可浏览的会话 | 空文件盒 | 用户在来源 App 创建对话后刷新 |

只有 `ready` 才能进入最后两项。纯空白查询不视为有效搜索。标题数量位置同时区分读取失败、等待刷新、统计中、已暂停和完整总数，不能将未知总数写成 `0`。

### 阅读区

- 有列表、未选中：等待选择插画 +「尚未选择会话」，描述说明正文与来源信息将在这里显示；不提前读取正文。
- 首次未连接：主阅读区使用「尚未连接会话来源」，描述补充支持的来源，按钮保留「连接来源 App」；不引导导入替代直读。
- 列表本身为空：阅读区沿用同一个真实状态，不再错误提示「选中一段对话」。
- 正文读取中：轻量进度，无空列表插画。
- 正文格式未支持：读取受阻插画，展示真实原因，**不显示重试按钮**。
- 正文读取失败：读取受阻插画和「重试读取」，仅重新读取选中会话。
- 正文成功但消息为空：空白纸张插画和「这段会话暂时没有消息」，不显示正常会话的结束标记。

### 档案与搜索

档案按「有内容 → 读取错误 → 初次加载 → 全库为空 → 有效搜索无结果 → 来源筛选为空」判断。整个档案库为空使用「还没有会话档案」及现有文件预览入口；单个来源没有档案不能使用全库为空提示。筛选为空可清空筛选，读取失败可重新加载，不伪装成新用户欢迎页。

搜索弹窗复用相同状态：未连接、加载、统计中和读取错误不能显示成「没有匹配」。有错误且仍有结果时保留结果与错误说明。没有保存连接的管理弹窗使用连接插画与原有连接入口。

## 视觉与组件契约

统一组件：`src/renderer/src/components/EmptyState.tsx`。`emptyStatePresets` 管理场景、默认文案、插画和播报语义；两个纯函数管理来源与档案的判定顺序。

- `hero`：主阅读空区，16px `h2`、184px 插画、最多一个主行动；窗口高不超过 700px 时插画为 144px。标题与描述间距收紧为 4px，描述仍为原有 12px，不改变插画和行动间距、居中、弱对比度和 tertiary 行动样式。
- `compact`：搜索弹窗、正文和管理弹窗中的局部空区，`h3`、120px 插画；有描述时与标题间距同样为 4px，不使用卡片底板或装饰图标。
- `quiet`：左侧列表等小空间只显示一句简短描述，不渲染标题、插画、进度装饰或固定脚注；待刷新用「刷新后查看会话」、确认为空用「暂无会话」、搜索为空用「未找到匹配的会话」。默认描述不超过 16 个字符，不照搬主阅读区的标题与说明组合；具体错误原因仍以纯文本替换默认描述。未选中时不重复阅读区主行动，必要的重试操作保留。
- `hero` 大空间固定保留「插画／进度 + 标题 + 一句简短描述 + 可用的主行动」。19 个场景均有独立描述，默认不超过 28 个字符，只补充标题未说明的原因、范围或能力；待刷新使用「等待刷新」+「连接位置已保留，会话列表尚未更新。」+ 刷新按钮。具体错误原因优先替换默认描述，不重复叠加。
- `compact` 保持按需说明，不因主阅读区补充描述而恢复冗长文案；`quiet` 继续只有一句提示。真实错误原因仍按需以纯文本展示，不截断诊断信息。
- 不展示「本地读取 · 只读浏览 · 按需接续」或档案入口的同类固定脚注；本地优先、只读等能力说明不在每个空占位重复。说明为空时不渲染段落，避免留下空白间距。
- 正常工作台同屏只在主阅读空区显示一幅空状态插画；侧栏既有隐私插画不属于空状态。弹窗是独立任务范围，可有自己的紧凑插画。
- 空占位标题、描述与小空间提示直接使用全局 `--ds-text-tertiary` 及 400 字重。全局三档文字共享 `--ds-text-rgb` 基色：浅色黑、深色白，primary／secondary／tertiary 仅以 88%／65%／40% 的颜色 alpha 分级。深色主题只切换基色，不重复定义三套灰色。不在组件中再叠加元素 opacity、局部颜色变量或 `data-empty-tone` 场景分支。字号、4px 文案间距和插画不变。
- 此变更统一全局三档文字定义，会同步影响正文、次要说明、会话元信息、数量和提示文字，而不只针对空占位。颜色按实际表面合成：surface-100／200／300 上正文主色和次要文字至少 4.5:1，辅助文字至少 2.5:1，不宣称辅助小字满足 4.5:1。品牌与错误语义色、按钮专用配色、焦点环和表面 token 不变；沿用文字 token 的控件前景同步更新。
- 只对 `.empty-illustration` 应用 50% 不透明度和 40% 饱和度，不改变 SVG、app icon 或侧栏插画。不降低整个空占位容器的不透明度，避免文字、按钮与焦点环一起变淡。透明插画没有图标底板、阴影、渐变背景和光栅嵌入。
- 空占位内的行动统一使用 DS 的 `tertiary` 按钮与 400 字重，不额外覆盖其前景色或背景色；保留悬停、键盘焦点环、禁用态和原有点击能力。不添加按钮专用的额外弱化或主题覆盖。
- 插画、标题、描述和按钮作为整体，在所属区域的可用空间内水平与垂直居中；左侧短提示也在空列表中居中，不再贴近列表顶部。阅读区页头、搜索输入和范围说明不计入空占位的可用区域。
- 只对仅含占位的列表／消息栏启用居中布局，不移动已有会话、正文或局部错误提醒。弹窗中的独立空区提供受窗口高度约束的最小展示空间；不以整屏高度、绝对定位或整体平移硬凑居中。
- 长文案可换行，不撑破窄列表。通过弹性容器与 `auto` 留白居中，空间不足时自动回到正常文档流并允许滚动，避免顶端内容被裁切，使低窗口中的行动仍可达。
- 插画为装饰：`alt=""`、`aria-hidden="true"`、`draggable={false}`。状态标题与说明承担语义；加载为 `status`，可恢复错误／未支持为 `alert`，静态空态不制造重复播报；`quiet` 不重复 live role。
- 加载点适配 `prefers-reduced-motion`。不让静态插画循环漂浮或强制获取焦点。
- 原始错误和导入内容一律 React 纯文本输出，不使用 `dangerouslySetInnerHTML`。行动由调用页面传入，不从来源内容生成可执行命令。

## 插画资产

基于当前用户定稿 `design/brand/pinekin-icon-approved.png` 的松貂身份，用内置生图生成六宫格原稿，再分格描摹真实贝塞尔路径，不用手绘几何图替代，不把 PNG 包在 `<image>` 中。

| SVG 文件（`src/renderer/src/assets/empty-states/`） | 动作与用途 |
| --- | --- |
| `disconnected.svg` | 松貂与连接端点；未连接、没有保存连接 |
| `empty.svg` | 松貂查看空文件盒；空列表、空档案、待刷新、暂停 |
| `search.svg` | 松貂与放大镜；有效搜索无结果 |
| `selection.svg` | 松貂与合起笔记本；有列表但未选择 |
| `unavailable.svg` | 松貂检查受阻文件；列表／连接／正文失败、部分可读、格式未支持 |
| `messages.svg` | 松貂展开空白纸张；正文没有可展示消息 |

原稿：`design/illustrations/empty-states/source/pinekin-empty-states.png`。运行时只加载六张 SVG，原稿不打入 renderer。

制作入口：`scripts/vectorize-empty-states.py`。仅为美术制作使用 Pillow／VTracer，不增加桌面运行时依赖。SVG 中记录原稿哈希、格子范围、VTracer 版本和参数；移除外部连通纸色背景，保留内部白纸与角色留白，按 `paper`、`apricot`、`terracotta`、`ink` 分层并提供深色主题颜色。某色在原稿中不存在时可保留空色层，不为凑色块补画或改变原始轮廓。

重新制作需预先具备 Pillow 11.3.0、VTracer 0.6.15，然后在工作区运行（用自己的 Python 环境替换 `python`）：

```bash
python -I scripts/vectorize-empty-states.py --help
```

这是从生成原稿得到的插画变体，不是 app icon 的矢量等价替换；不修改定稿 icon 或侧栏既有插画。
