## 共享弹窗轻微缩放与淡入淡出（2026-10-19，当前）

- 连接、来源／档案搜索、导入预览与交接弹窗共用动效：180ms 淡入并从 `scale(0.97)` 恢复到原尺寸，140ms 反向缩小淡出；以中心为原点，无位移、弹跳或尺寸重排。原有布局、颜色、圆角及标题不变。
- `DsDialogPresence` 包裹整个条件弹窗子树；关闭按钮、遮罩、Escape、返回、选择结果及程序关闭先照常更新业务状态，仅保留最后一次渲染的原节点至退场完成，不克隆 DOM、不推迟业务回调。退场时设为 `inert`、从辅助技术树隐藏，避免重复交互；自身退场动画结束才卸载并恢复触发焦点，子元素和遮罩事件不提前卸载。
- 遮罩只做同步透明度渐变。系统“减少动态效果”覆盖面板和 `::backdrop`，关闭前或退场中启用均立即清理；动画事件丢失时 180ms 兜底释放 modal，重新打开则取消旧清理。此约定替代下方历史记录中“不使用弹窗缩放动效”的限制，业务流程仍不依赖动画完成。
- 单元回归覆盖全部关闭入口、原节点及输入内容保留、重复事件、减少动态效果、事件丢失兜底、快速重开及焦点恢复。桌面验证仅允许复用现有主 dev；无法安全接入时暂停 E2E，不再另开后台或隐藏 Electron 实例。

## 微型流动点加载与按筛选范围提示更新（2026-10-18，当前）

- 来源扫描的动画放在侧栏各行右侧 `.count`，原位替换数量，只有对应来源正在扫描才显示；其他已完成来源仍显示数字，全部扫描完成后「所有会话」恢复总数。不增加单独加载行，不移动来源图标或文字，不改变现有行高和右侧对齐。
- 来源侧栏、列表标题、列表内加载占位、搜索摘要及分页等待共用本地 `LoadingMark`：18 × 12px 固定占位，三枚 3px 圆点依次围绕自身中心等比缩放，倍率 0.5–1.15（占位直径 1.5px，峰值 3.45px），显式 `transform-origin: center`，不附加任何位移，全程保持正圆，1.2s 循环。三点峰值从左到右相隔 180ms，使用 `cubic-bezier(0.37, 0, 0.63, 1)`；单点 15% 时达到大小／亮度峰值，40% 时回到 0.85 倍／0.45 透明度，再于 85% 渐退至 0.5 倍／0.35 透明度。较明显的峰值依次右行，低亮尾迹相互重叠并接入下一轮，避免对称呼吸削弱方向感，也不增加整组静止段。负延迟 -180 / -1200 / -1020ms 使初始即进入接力相位，右侧尾迹回落时下一轮左点已开始变化；替代前一版 24 × 18px 页签动画，不再以放大图展示加载效果。仅动画 transform / opacity，无定时器、逐帧 React 更新或新增扫描。扫描期间列表描述保留「发现 N 条」，稳定状态仍显示已加载数量；不显示加载中文字，辅助技术仍可获得明确状态名称。主阅读区的原有加载说明保持不变。
- 动画继承当前位置的文字颜色，不另加强调品牌色；减少动态效果时停止循环，保留三个静态圆点。按钮真实禁用状态与动画无关，动画结束事件不触发数据请求。
- 「列表有更新」只由当前来源范围的完整结果指纹变化触发；「搜索结果有更新」还包含当前关键词的匹配范围。全局目录版本变化只启动轻量核对，不直接提示，不因手动无变化刷新误报。其他 App 或关键词外的变化不重排现有结果、不阻断继续分页；未加载页内的变化仍可识别。
- 指纹只对已有内存目录元数据计算，覆盖排序、条目增删、标题、时间、种类及来源 revision，忽略按需读取产生的已读状态；不读取全部正文。核对请求至多返回一条条目和指纹，未变化不重新拉取已加载分页。来源切换、搜索词变化或关闭弹层后的迟到响应作废；正文更新继续按选中会话自身 revision 单独判断。
- 验证：相关 168 项测试、完整覆盖率 54 文件 740 项通过，行 98.18%；刷新专项 5 项均有通过结果（新增 Cindy 用例修正合成正文、分页滚动基线与标题选择器后定向通过）。扫描轮询失败时错误优先于动画，最后补充的相关界面回归 156 项、类型检查、构建及页签动画专项均通过。桌面测试只用合成数据，隔离 home/userData，替换剪贴板／文件选择器，窗口从创建起隐藏，show/focus 事件为空。本批未重跑完整桌面套件，留待并行来源归属改动整合后统一验收。

### 独立化决策

- `tokens.css` 保存必要 `--ds-*` token，`styles.css` 只引用语义颜色；不整体复制宿主全局 CSS。
- `components/ui.tsx` 是 Staithe 的轻量 `DsButton` / `DsDialog` / `DesignIcon` 实现，不是 NewMax 组件包链接。没有跨仓库 import、软链接、Zustand store 或 `window.api`。
